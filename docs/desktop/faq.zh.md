# 桌面端常见问题（FAQ）

## 安装

**Q：安装时 Windows 提示"Windows 已保护你的电脑"，是不是安装包有问题？**
A：不是。安装包**未做代码签名**，SmartScreen 对未签名程序一律拦截。点 **更多信息 → 仍要运行** 即可。
如果你不放心，先按 [安装文档](./install.zh.md) 核对 SHA256。

**Q：杀毒软件把安装包隔离了怎么办？**
A：先把该文件加入信任后重新安装。若反复被隔离，请重新下载并核对 SHA256；哈希一致仍被拦，说明是本机安全策略所致，平台不会提供绕过手段。

**Q：需要管理员权限吗？**
A：不需要。默认按用户安装。只有少数"安装系统级依赖"的本机任务会触发 UAC。

**Q：安装包有多大？装完占多少空间？**
A：当前版本安装包约 517 MB（含内置运行时）；安装后建议预留 2 GB 左右。

**Q：支持 macOS / Linux 吗？**
A：当前公开版本只提供 Windows x64 安装包。其他平台请先用网页端或小程序端。

## 启动与登录

**Q：启动后白屏 / 一直转圈？**
A：按顺序排查：① 网络能否打开 `deepresvalue.com`；② 关闭代理软件后重试；③ 退出应用重新启动；④ 重启电脑。
仍不行请把应用目录下的日志文件反馈给支持。

**Q：登录失败？**
A：桌面端与网页端共用账号。先在浏览器确认能登录；浏览器能登录而桌面端不能，多半是本机网络或代理策略。

**Q：能同时开多个窗口 / 多个实例吗？**
A：同一份用户数据只允许一个实例运行；再次启动会聚焦已有窗口。这是为了避免两个实例争抢同一工作区。

## 使用

**Q：桌面端和网页端有什么区别？**
A：界面与功能同源。差别只有两点：① 原生窗口体验（通知、多任务）；② **可选的"本机执行"**能力。
不需要本机执行的话，网页端就够了。

**Q：默认会在我的电脑上跑东西吗？**
A：不会。执行位置每次任务显式选择；默认是云端。详见 [本地执行与隐私](./local-execution.zh.md)。

**Q：Agent 会读我的整个硬盘吗？**
A：不会。默认档位只能在你选定的工作区目录内读写；工作区之外需要"完全访问"档位并由你显式选择。

**Q：工作区选错了 / 想换目录？**
A：设置里可以更换。换目录只是改"以后在哪儿干活"，不会移动或删除已有文件。

**Q：本机执行的文件会上传到云端吗？**
A：不会自动上传。只有你主动上传，或 Agent 把产物作为交付物回传时才会上云。

**Q：离线能用吗？**
A：不能。平台能力依赖云端服务；断网时只能查看本地已缓存内容。

**Q：长任务能挂着吗？**
A：可以。长任务以作业形式运行，可看进度、看输出、随时停止；关闭窗口不会自动杀掉后台作业。

## 升级与卸载

**Q：怎么升级？**
A：设置 → 账号页底部「软件更新」；或下载新安装包覆盖安装。升级不需要重新登录，工作区文件不受影响。

**Q：升级失败怎么办？**
A：先完全退出应用再重试；仍失败就手动下载最新安装包覆盖安装。你的会话与工作区文件不受影响。

**Q：卸载会删掉我的文件吗？**
A：不会删工作区里的文件。卸载会删除程序文件与内置运行时；用户数据目录可能保留，可手动清理。
云端会话与产物不受影响，重新登录即可见。

**Q：卸载后还有残留吗？**
A：可能有：用户数据目录（配置与会话缓存）以及你自己的工作区文件。前者可手动删除，后者是你自己的数据，平台不会替你删。

## 数据与隐私

**Q：平台能看到我的本机文件吗？**
A：读不到你工作区之外的东西；工作区内的读写由你的授权档位决定。本机执行的命令与输出会记录在会话日志中。

**Q：分享链接安全吗？**
A：分享是**链接级**：拿到链接的人就能访问。不要分享含敏感信息的链接。

**Q：会话和产物保存在哪？**
A：云端存储，随账号同步；工作区里的本机文件不构成持久化数据。
