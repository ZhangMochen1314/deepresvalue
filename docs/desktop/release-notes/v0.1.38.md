## 本次更新

### 设置页精简

- 移除只读的「本机环境」页——该页只做展示、没有可操作项，对用户没有实际价值。
- 「软件更新」并入账号页，不再单独占用导航项。
- 设置导航由 6 项减为 5 项。

### 不变的部分

- Agent 能力、工具与专家体系不变。
- 本地执行的权限模型、工作区边界、进程卫生机制不变。
- 安装/升级方式不变，工作区文件不受影响。

## 安装

1. 下载 `DeepResValue-0.1.38-setup.exe`。
2. 校验 SHA256（见上）。
3. 双击安装；SmartScreen 提示点「更多信息 → 仍要运行」。
4. 首次启动用网页端同一账号登录，选择工作区目录。

详见 [安装与升级](../install.zh.md)。

## 升级

- 应用内：**设置 → 账号页底部「软件更新」**。
- 或下载本版本安装包覆盖安装；不需要重新登录。

## 已知问题

- 安装包未做代码签名，首次运行必然触发 SmartScreen 提示（这是当前发布策略，不是缺陷）。
- 卸载不删除工作区文件，也不会清理全部用户数据目录（见 [FAQ](../faq.zh.md)）。
