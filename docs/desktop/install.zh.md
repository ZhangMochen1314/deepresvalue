# 桌面端安装与升级（Windows）

## 1. 下载

| 渠道 | 地址 |
|------|------|
| GitHub Releases（推荐，可校验） | <https://github.com/ZhangMochen1314/deepresvalue/releases/latest> |
| 官方网站 | <https://deepresvalue.com/> |

下载文件名形如 `DeepResValue-<版本号>-setup.exe`。当前公开版本、文件大小与 SHA256 见仓库根目录的 [RELEASES.md](../../RELEASES.md)。

> 只从上述两个渠道下载。第三方站点转发的安装包无法保证未被篡改。

## 2. 校验（建议做，30 秒）

在下载目录打开 PowerShell：

```powershell
Get-FileHash .\DeepResValue-0.1.38-setup.exe -Algorithm SHA256
```

把输出的哈希与 [RELEASES.md](../../RELEASES.md) 中该版本的值逐字比对。**不一致就不要安装**，重新下载或换渠道。

## 3. 系统要求

| 项 | 要求 |
|----|------|
| 操作系统 | Windows 10（1809 及以上）/ Windows 11 |
| 架构 | x64 |
| 内存 | 建议 8 GB（最低 4 GB） |
| 磁盘 | 约 2 GB 可用空间（安装包约 517 MB，安装后更大） |
| 网络 | 必须联网；需能访问 `deepresvalue.com` |
| 权限 | 普通用户即可安装（按用户安装，不需要管理员） |

## 4. 安装

1. 双击安装包。
2. **SmartScreen 提示**：因为安装包**未做代码签名**，Windows 会显示"Windows 已保护你的电脑"。
   点 **更多信息** → **仍要运行**。这是预期行为，不是安装包损坏。
3. 选择安装目录（默认按用户安装，可改路径）。
4. 等待完成。安装程序**不会**自动启动应用（避免安装脚本替你做事），请从开始菜单或桌面快捷方式启动。

> 若企业环境有应用白名单/杀软策略，可能需要在策略侧放行该安装包；平台不提供绕过系统安全策略的方法。

## 5. 首次启动

1. 启动 DeepResValue。
2. 用**与网页端相同的账号**登录。
3. 选择**工作区目录**——这是本机执行时的默认工作目录，也是你放本机文件的地方。
   之后可在设置里更换；换目录不会移动已有文件。
4. 进入主界面。左侧是会话，中间是对话，右侧是文件与产物。

## 6. 升级

- 应用内升级：**设置 → 账号页底部「软件更新」**。
- 也可以直接下载新版本安装包覆盖安装；安装目录会被复用，工作区文件不受影响。
- 升级不需要重新登录。

## 7. 卸载

- 方式一：Windows **设置 → 应用 → 已安装的应用 → DeepResValue → 卸载**。
- 方式二：安装目录下的 `Uninstall DeepResValue.exe`。

**卸载会删掉什么、不会删掉什么**：

| 对象 | 卸载后 |
|------|--------|
| 程序文件、内置运行时 | 删除 |
| 应用配置与会话缓存（用户数据目录） | 可能保留，可手动清理 |
| **你的工作区目录（本机文件）** | **不会删除** |
| 云端会话与产物 | 不受影响，重新登录即可见 |

## 8. 常见安装问题

| 现象 | 处理 |
|------|------|
| SmartScreen 拦截 | 更多信息 → 仍要运行（见第 4 节） |
| 杀软报毒/隔离 | 加入信任后重装；如仍被隔离，用官方渠道重新下载并核对 SHA256 |
| 安装到一半失败 | 检查磁盘空间与安装目录权限；关闭占用该目录的程序后重试 |
| 启动后白屏/卡在加载 | 检查网络能否访问 `deepresvalue.com`；重启应用；仍不行看 [FAQ](./faq.zh.md) |
| 安装包哈希不一致 | 不要安装，重新下载 |
