# 本地执行与隐私（桌面端）

> 一句话：**默认什么都不在你的电脑上跑**。只有当你在界面上主动选择"在本机执行"，桌面端才会触碰本机环境、
> 文件或进程；选择之后，边界是三档权限 + 工作区目录 + 可随时取消。

---

## 1. 为什么需要"本机执行"

云端隔离执行覆盖绝大多数任务，但它看不到你的电脑。下面几类任务只能在本机做：

- 处理**本机文件**（不经过云端上传）；
- 调用**本机已装软件**（专业软件、本机工具链、内网客户端）；
- 使用**本机环境变量与凭证**（例如企业内网、已登录的本地服务）；
- 需要**长时间驻留**的本地任务（批量转码、长跑脚本）。

这就是桌面端存在的理由，也是它唯一的"多出来的能力"。

---

## 2. 如何开启

1. 在对话里选择执行位置：**本机**（默认是云端）。
2. 首次使用会要求你确认工作区目录——本机执行只能在你选定的目录范围内活动。
3. 发送任务。任务卡片会显示执行位置、权限档位与耗时。

**没有"自动在本机执行"的路径**。执行位置是每次任务显式选择的；换会话不会沿用上一次的授权。

---

## 3. 三档权限

| 档位 | 能做什么 | 不能做什么 | 何时用 |
|------|----------|------------|--------|
| **只读**（read-only） | 读取工作区内容、查看环境信息 | 写文件、改配置、装依赖 | 只想让 Agent 看，不想让它动 |
| **工作区读写**（workspace-write，默认） | 在工作区目录内读写、跑脚本、装依赖 | 工作区之外的路径 | 绝大多数本机任务 |
| **完全访问**（full） | 读写工作区之外的路径 | —— | 明确需要跨目录操作时 |

权限档位**按任务生效**，不会"一次授权永久生效"。

---

## 4. 边界：工作区

- 工作区是你选定的一个目录。默认档位下，读写都被限制在这个目录里。
- 工作区之外的路径需要**完全访问**档位，且由你显式选择。
- 换工作区只改"以后在哪儿干活"，不会移动或删除已有文件。

---

## 5. 进程卫生

本机执行不是"把命令丢进你的终端就不管了"：

| 机制 | 行为 |
|------|------|
| 超时 | 每个任务有执行上限；到点终止，返回可读原因 |
| 取消 | 你随时可以取消；取消会终止该任务派生的**整棵进程树**，不留孤儿进程 |
| 后台任务 | 长任务以作业形式运行，可查看进度、查看输出、随时停止 |
| 输出落盘 | 命令的标准输出与错误分别落日志，可回溯，不吞错 |
| 审计 | 每次本机执行在任务日志卡里留下记录（命令、目录、退出码、耗时） |

---

## 6. 需要额外确认的动作

以下动作**不会静默发生**，必须经过确认，否则直接拒绝（fail-closed）：

- 在**工作区之外**创建或修改内容；
- 创建/删除本机环境（例如新建 Python、R 环境）；
- 安装系统级依赖；
- 需要管理员权限的操作（会走 Windows 的 UAC 提示）。

如果你在某些环境下没有确认通道（例如策略禁用了确认对话框），这些动作会被**直接拒绝**，而不是降级放行。

---

## 7. 数据去了哪里

| 数据 | 落点 | 是否跨设备可见 |
|------|------|----------------|
| 你在工作区里的本机文件 | 你的电脑 | 否（除非你上传） |
| 本机执行的命令输出 | 本机会话日志 + 会话记录 | 会话记录随账号同步 |
| 你上传到会话的文件 | 云端存储 | 是 |
| 正式交付物（回传后） | 云端存储 | 是 |

**要点**：本机文件不是平台的持久化数据。你换了电脑、或卸载了桌面端，工作区里的文件仍然在你自己机器上，
但平台侧不会替你保留副本。

---

## 8. 隐私边界（不夸大）

- **传输全程加密**（HTTPS / WSS）。
- **不做端到端加密承诺**：云端任务需要读取文件内容才能分析；本机任务不上传文件内容，但任务描述与执行记录会同步到会话。
- **不做"仅本人可访问"的绝对承诺**：分享是链接级，拿到链接即可访问。
- **不上传你的工作区文件**：除非你在任务里主动上传，或 Agent 把产物回传为交付物。

---

## 9. 建议的安全用法

1. 给 Agent 单独建一个工作区目录，不要把整个磁盘或家目录设成工作区。
2. 默认用"工作区读写"，只在确实需要跨目录时临时切"完全访问"。
3. 涉及敏感凭证时，用本机环境变量，不要把密钥写进对话。
4. 长时间任务用作业形式跑，方便随时查看与停止。
5. 不用了就取消，别把任务挂在后台过夜。
