# 桌面端 / Desktop

DeepResValue 桌面端是**可选的**原生客户端：基于 Chromium 的原生窗口，复用网页端的同一套实现，
并额外提供一项网页端做不到的能力——**用户显式选择后，在本机原生执行任务**。

> 不装桌面端也能用。网页端（手机 / 平板 / 电脑浏览器）是全功能主入口；桌面端解决的是
> "需要原生窗口体验"和"需要在本机跑东西"两类需求。

## 一句话定位

| 场景 | 建议用哪个端 |
|------|--------------|
| 分析、写作、排版、文献检索 | 网页端即可（零安装） |
| 长时间任务、需要原生通知、多窗口 | 桌面端 |
| 要处理本机文件、调用本机软件或内网资源 | 桌面端 + 显式选择"本机执行" |
| 手机上随手用 | 小程序端 / 手机浏览器 |

## 版本与校验

当前公开版本、安装包大小与 SHA256 见 [RELEASES.md](../../RELEASES.md)。
安装包**未做代码签名**，Windows 首次运行会弹 SmartScreen 提示——这是预期行为，处理方式见安装文档。

## 数据放在哪

- 会话、上传件、正式产物：**云端**（换设备可见）。
- 桌面端的本机文件：留在你的电脑上，**不构成持久化**；要跨设备查看必须回传云端。
- 默认不在你的电脑上执行任何东西；本机执行需要你在界面上主动选择。
