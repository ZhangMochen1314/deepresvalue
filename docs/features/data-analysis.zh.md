# 数据分析

深度研值最核心的能力——上传数据文件，用中文描述分析需求，AI 自动完成从方法选择到结果输出的全过程。

## 工作原理

上传你的数据文件（支持 Excel、CSV、PDF、Word、Stata、SAS、SQLite 等 80+ 格式），用中文描述分析需求。AI 会：

1. 自动理解你的研究意图
2. 从 **100+ 统计与机器学习方法** 中匹配最优方案
3. 自动编写 Python 代码并执行
4. 输出期刊标准的三线表、回归表、可视化图表

## 支持的分析方法

| 类别 | 方法示例 |
|------|----------|
| 传统计量 | DID（双重差分）、IV（工具变量）、RDD（断点回归）、合成控制法、面板固定效应 |
| 因果机器学习 | DML（Double Machine Learning）、因果森林、Meta-learner、Neural Causal |
| 统计检验 | 描述统计、相关性分析、t 检验、方差分析、卡方检验 |
| 机器学习 | 随机森林、XGBoost、神经网络、聚类分析、主成分分析 |
| 生存分析 | Kaplan-Meier 曲线、Cox 比例风险、竞争风险模型 |
| 空间计量 | 空间权重矩阵、莫兰指数、地理加权回归 (GWR) |
| 文本分析 | BERT/LLM 文本分类、情感分析、主题建模 |

## 使用步骤

1. **上传数据文件**
2. **描述分析需求**
3. **查看分析结果**
