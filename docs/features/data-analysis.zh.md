# 数据分析

深度研值最核心的能力——上传数据文件，用中文描述分析需求，AI 自动完成从方法选择到结果输出的全过程。

## 工作原理

上传你的数据文件（支持 Excel、CSV、PDF、Word、Stata、SAS、SQLite 等 80+ 格式），用中文描述分析需求。AI 会：

1. 自动理解你的研究意图
2. 从 **100+ 统计与机器学习方法** 中匹配最优方案
3. 自动编写 Python 代码并执行
4. 输出期刊标准的三线表、回归表、可视化图表

## 支持的分析方法

| 类别 | 方法示例 |
|------|----------|
| 高级计量 | DID（双重差分）、IV（工具变量）、GMM、RDD（断点回归）、合成控制法、面板固定/随机效应 |
| 因果机器学习 | DML（Double Machine Learning）、因果森林、Meta-learner、Neural Causal |
| 贝叶斯统计 | 贝叶斯推断、MCMC（Stan/PyMC）、分层贝叶斯模型、贝叶斯网络、贝叶斯优化 |
| 结构方程与心理测量 | 结构方程模型 SEM、验证性因子分析 CFA、量表信效度（Cronbach's α）、IRT 项目反应理论 |
| 流行病学与公共卫生 | 队列/病例对照研究、Meta 分析、生存分析与竞争风险（Cox/Fine-Gray）、倾向评分匹配 PSM |
| 统计检验 | 描述统计、相关性分析、t 检验、方差分析、卡方检验 |
| 机器学习与 AI | 随机森林、XGBoost、深度学习（CNN/RNN/Transformer）、NLP 文本挖掘、模型可解释性（SHAP/LIME） |
| 生存分析 | Kaplan-Meier 曲线、Cox 比例风险、竞争风险模型（Fine-Gray） |
| 空间计量 | 空间权重矩阵、空间自相关（莫兰指数）、SAR/SEM/SDM 空间计量模型、地理加权回归 (GWR) |
| 生信分析 | 基因组/转录组/蛋白组差异分析、富集分析（GO/KEGG）、NGS 测序数据分析 |
| 土木/机械/自动化 | 结构力学与有限元分析、机械仿真、控制系统（PID/状态空间）、电子电路与 PCB 设计、信号处理 |
| 农业/能源/环境 | 农业经济学、能源计量与碳排放、碳核算与双碳研究、遥感与 GIS 空间分析、环境库兹涅茨曲线 |
| CAD 分析 | 计算机辅助设计、工程制图分析、三维建模数据处理 |
| 文本分析 | BERT/LLM 文本分类、情感分析、主题建模 |
