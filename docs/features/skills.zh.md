# 科研领域专家

深度研值内置 **129 位科研领域专家**，覆盖科研全流程。每位专家是对应领域的专业工作流和工具组合包。选择匹配的专家后，AI 将加载对应领域的专业知识与分析工具，输出质量更高。各类科研数据内置，只需说需求 Agent 自主调用。前沿科研分析方法全覆盖——没有做不了的科研分析方法，Agent 实时在对应领域专家指导下写代码、云端执行。

## 使用步骤

1. **打开专家面板**
2. **选择合适的专家**
3. **开始对话**

## 专家如何工作

选择专家相当于为 AI 加载了一套 **专业领域知识库**：

- **实证分析专家**：AI 了解各类计量方法的适用条件、假设检验流程
- **竞赛专家**：AI 熟悉竞赛评分标准、获奖论文写作模式
- **学科专项专家**：AI 加载对应学科的专业工具库和术语体系

## 示例场景

```text
选择「全流程实证分析」专家后：
用 DID 方法分析政策效应，需要做平行趋势检验、安慰剂检验和稳健性检验。
```

```text
选择「专业科研绘图」专家后：
根据回归结果画森林图，标注 95% 置信区间，导出 300dpi 高清 PNG。
```

> 选择匹配的专家后，AI 将加载对应领域的专业知识与分析工具，输出质量显著提升。不选专家时 AI 也能工作，但精准度可能较低。

> 专家列表持续更新中，如果找不到完全匹配的专家，选择最接近的即可，AI 会自动适配。
