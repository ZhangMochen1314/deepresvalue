# 技能系统

深度研值内置 **100+ 个专业技能**，覆盖科研全流程。选择匹配的技能后，AI 将加载对应领域的专业知识与分析工具，输出质量更高。

## 技能分类

|----------|------------------|----------|
| 🔬 实证分析 | Python 全流程实证分析、R 全流程实证分析、面板分析、空间计量、时间序列、中介调节、多层HLM | 各类量化研究 |
| 🤖 因果推断 | 贝叶斯因果推断、机器学习因果、DID/RDD/IV/合成控制 | 前沿方法论 |

## 使用步骤

1. **打开技能面板**
2. **选择合适的技能**
3. **开始对话**

## 技能如何工作

选择技能相当于为 AI 加载了一套 **专业领域知识库**：

- **实证分析技能**：AI 了解各类计量方法的适用条件、假设检验流程
- **竞赛技能**：AI 熟悉竞赛评分标准、获奖论文写作模式
- **学科专项技能**：AI 加载对应学科的专业工具库和术语体系

## 示例场景

```text
选择「全流程实证分析」技能后：
用 DID 方法分析政策效应，需要做平行趋势检验、安慰剂检验和稳健性检验。
```

```text
选择「专业科研绘图」技能后：
根据回归结果画森林图，标注 95% 置信区间，导出 300dpi 高清 PNG。
```

> 选择匹配的技能后，AI 将加载对应领域的专业知识与分析工具，输出质量显著提升。不选技能时 AI 也能工作，但精准度可能较低。

> 技能列表持续更新中，如果找不到完全匹配的技能，选择最接近的即可，AI 会自动适配。
