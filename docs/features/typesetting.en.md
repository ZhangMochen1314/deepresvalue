# Typesetting

DeepResValue includes built-in LaTeX and Word typesetting engines, **all cloud-pre-configured and ready to use** — no local TeX distribution or Office installation required. Open your browser and start typesetting immediately. Generates journal-standard professional charts and documents, ready to paste directly into your paper.

## Features

- **LaTeX typesetting engine** generates journal-standard professional charts
- **Multiple academic chart types**: three-line tables, regression tables, structural equation diagrams, event study plots — directly usable in papers
- **Multi-format export**: PDF / Word / LaTeX source, submission-ready formatting in one click
- **Professional scientific plotting**: Built-in DeepResValue-SciPlot skill covering 20+ academic chart types

## Step-by-Step Usage

1. **Complete data analysis** — First use the data analysis feature to run your statistical analysis, or directly upload content for typesetting.
2. **Specify typesetting needs** — Tell the AI the format you need (three-line table / regression table / specific journal format, etc.).
3. **Receive typeset output** — The AI uses the LaTeX engine to produce professional typeset results. Download as PDF, Word, or LaTeX source.
