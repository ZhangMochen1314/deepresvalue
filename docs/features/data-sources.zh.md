# 数据源管理

没有数据也不用担心——深度研值的数据获取能力分两层：**平台预置面板数据**与**专家驱动的数据搜集**。用中文一句话描述需求，AI 自动匹配数据源并返回结构化数据。

## 平台预置面板数据

数据引擎直读权威 Parquet 文件，覆盖以下 6 个数据集：

| 数据集 | 覆盖范围 |
|--------|----------|
| 📊 **城市宏观面板** | 2000-2023 年，GDP、人口、就业、产业、财政、贸易、金融等 325 个指标 |
| 🏙️ **省级宏观面板** | 2000-2023 年，人口、经济、财政、教育、就业等 2468 个指标 |
| 🏘️ **县域面板** | 2000-2023 年，人口、经济、财政、教育、卫生等 61 个指标 |
| 💼 **上市公司财务面板** | 2000-2023 年，30 个核心财务指标 |
| 🏢 **上市公司治理控制变量** | 2000-2023 年，财务、治理、市场等 84 个指标 |
| 📍 **上市公司行业与地理位置** | 2000-2023 年，证券代码、行业、所属省份 |

## 专家驱动的数据搜集

AI 自动加载对应数据搜集专家，从外部数据源获取结构化数据：

| 领域 | 可搜集的数据 |
|------|--------------|
| 📈 **金融行情** | 沪深 A 股/指数/行业/实时行情/历史行情；A 股/港股/美股/基金/债券/宏观 EDB |
| 🏭 **中国经济数据** | 省市县三级区域经济面板（1990-2024）、上市公司财务（5822 家/857 项指标）、企业地理定位、空间边界 |
| 🗺️ **中国空间数据** | 省市县行政区划边界 GeoJSON、GB/T 2260 行政区划代码 |
| 🏥 **美国健康数据** | NHANES、BRFSS、NHIS、NVSS、WONDER 等 CDC 公开数据 |
| ⚕️ **医学数据库** | ClinicalTrials.gov 临床试验、WHO 全球卫生指标、PubChem 化合物、MeSH/RxNorm 术语、NCBI 基因信息 |
| 🧬 **生物数据** | EMBL-EBI 生物数据库、bioRxiv 预印本 |
| 📚 **文献检索** | NCPSSD 中文期刊、CNKI 摘要增强、arXiv 英文预印本、PubMed 生物医学、Crossref 元数据 |
| 🌐 **网页正文** | 指定 URL 的网页正文内容提取 |

## MCP 外部连接器

平台已接入**数十个 MCP 连接器**，在对话中直接调用第三方专业数据源——无需离开平台、无需切换网页。AI 会自动判断是否需要调用连接器，你也可以主动触发。

| 连接器 | 类型 | 说明 |
|--------|------|------|
| **智慧芽 PatSnap** ★ | 专利与知识产权 | 官方 34 个 MCP 服务：专利检索/分析/估值/景观、临床试验、药物资产、靶点疾病、监管指南、TRIZ 引擎等 |
| **北大法宝** | 法律检索 | 中国法律法规、司法案例、学术期刊检索 |
| **万得 Wind** | 金融数据 | 上市公司财务、宏观经济、行业数据 |
| **同花顺 iFinD** | 金融行情 | A 股、公募基金、宏观数据、债券、财经新闻 |
| **企查查** | 企业信息 | 工商注册、风险信息、知识产权、经营数据、历史变更 |
| **百度 AI 学术搜索** | 学术检索 | AI 驱动的学术文献智能搜索 |
| **百度文库 / OCR** | 文档处理 | 文献图像识别、文档解析 |
| **开放学术四件套** | 学术元数据 | arXiv / PubMed / Crossref / Semantic Scholar（免认证） |
| **腾讯地图** | 地理服务 | 地理编码、POI 搜索、路线规划 |
| **腾讯问卷 / 会议** | 协作工具 | 问卷调研、会议纪要 |
| **TickDB** | 量化行情 | 外汇、贵金属、指数、美股/港股/A 股、加密货币量化数据 |

> 连接器持续扩展中。部分连接器（如北大法宝、万得 Wind）需要你填入自己的 API Token（BYOK），平台不额外收取服务费。

## 使用步骤

1. **描述数据需求**
2. **AI 自动匹配数据源**
3. **直接用于分析**

## 示例 Prompt

```text
帮我找 2015-2023 年地级市 GDP 和财政收入数据。
```

```text
获取某上市公司近 5 年的财务指标（营收、净利润、资产负债率）。
```

```text
查找 NHANES 调查中 2017-2020 年成年人的体重指数数据。
```

```text
检索近 3 年关于数字经济与碳排放的 PubMed 文献。
```

> 描述需求即可，AI 自动匹配数据源并返回结构化数据，**免费、免中介、免复杂查询**。

> 数据搜集能力持续扩展中，如需特殊领域数据，建议先在对话中描述需求，AI 会告知是否支持。
