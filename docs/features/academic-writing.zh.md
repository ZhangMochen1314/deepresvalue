# 学术写作

深度研值覆盖论文写作的每一个环节——从选题到答辩，全周期辅助。

## 覆盖的写作阶段

| 阶段 | AI 能帮你做什么 |
|------|----------------|
| **选题阶段** | 评估选题可行性，推荐前沿方向 |
| **开题阶段** | 自动生成开题报告框架，填充文献综述 |
| **正文写作** | 润色段落、优化表达、自动检查学术规范 |
| **数据分析** | 50+ 方法自动匹配，出三线表 + 图表 |
| **格式检查** | 自动检查参考文献格式、排版规范 |
| **答辩准备** | 生成答辩 PPT 大纲，梳理答辩逻辑 |

## 使用步骤

1. **确定写作阶段**
2. **提供背景信息**
3. **获取写作输出**

## 示例 Prompt

```text
帮我评估「数字普惠金融对农村创业的影响」这个选题的可行性，分析数据获取难度和方法选择。
```

```text
帮我生成开题报告框架，研究主题是「碳排放权交易对企业绿色创新的影响」。
```

```text
请对以下段落进行学术润色，保持学术风格，优化逻辑连贯性。
```

```text
帮我梳理答辩逻辑，论文题目是「人工智能对劳动力市场的就业极化效应研究」。
```

> 学术模式下 AI 输出自动匹配学术规范，包括引用格式、段落结构和表达风格。

> AI 生成的学术内容建议在使用前进行个人化修改，确保符合你的研究特色和导师要求。
