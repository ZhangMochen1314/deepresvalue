# 竞赛建模

深度研值内置 **100+ 个专业技能**，覆盖全学科科研场景，其中竞赛专项持续更新，确保每个国家级竞赛都有专属技能指导。

## 支持的竞赛类型

### 🔢 数学建模（CUMCM / MCM-ICM）

- 覆盖**全国大学生数学建模竞赛（CUMCM）**与**美国大学生数学建模竞赛（MCM/ICM）**
- AI 辅助建模 + 自动编程求解 + LaTeX 排版输出
- 微分方程、优化模型、神经网络、随机过程、空间计量全覆盖
- 从问题分析到 20 页论文全流程

### 🏆 全国统计建模大赛

- `DeepResValue-StatModel` 专属技能
- 覆盖选题论证 → 数据处理 → 模型构建 → 报告撰写全流程
- DML / DID / RDD / 因果森林 / 合成控制——**往年获奖作品常用方法全部支持**

### 🚀 挑战杯

- 覆盖**「挑战杯」全国大学生课外学术科技作品竞赛**与**大学生创业计划竞赛**
- 内置专项技能，辅助选题论证、研究设计、数据分析与报告撰写
- AI 辅助市场分析 + 财务预测 + 风险评估

### 💡 三创赛

- 覆盖**全国大学生电子商务"创新、创意及创业"挑战赛**
- 内置三创赛全流程制胜技能，覆盖创新立项 → 商业策划 → 实践验证 → 路演答辩
- 商业计划书、市场调研分析、数据可视化、路演 PPT 一站式输出

## 使用步骤

1. **选择竞赛技能**
2. **描述竞赛题目**
3. **逐步完成任务**

## 示例 Prompt

```text
这是统计建模大赛的题目，请帮我做选题论证，分析数据可得性，推荐适合的计量方法。
```

```text
请用 DML 方法分析这道统计建模题的因果效应，做交叉验证和稳健性检验。
```

```text
帮我用 LaTeX 排版这篇数学建模论文，按照国赛论文格式要求。
```
