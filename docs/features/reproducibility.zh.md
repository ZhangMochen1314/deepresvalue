## 为什么重要

答辩时评委问你「这个结果怎么来的」——直接展示完整的分析路径和代码，当场证明结果的可靠性。

## 透明化内容

### 📋 完整代码与日志

每个分析任务完成后，你可以查看：

- **完整 Python 代码**：AI 执行的每一行代码都保留
- **执行日志**：每一步的运行状态、中间结果
- **数据追溯**：输入数据 → 清洗 → 分析 → 输出的完整链路
### 🧩 子任务卡片

复杂任务会被自动拆解为多个子任务，以折叠卡片形式展示：

1. 每张卡片显示子任务名称（如「搜索相关文献」「执行数据清洗」）
2. 点击 **▶ 展开** 查看该子任务的详细过程与结果
3. 所有子任务完成后，AI 汇总输出最终结论
### 🔧 工具调用可视化

在 AI 分析过程中，你可以实时看到它调用了哪些工具：

| 面板 | 展示内容 |
|------|----------|
| **搜索面板** | 联网搜索时显示检索到的来源数量和摘要 |
| **代码执行面板** | 执行 Python 代码时显示代码内容、运行状态和输出 |
| **文件读取提示** | 读取上传文件时显示文件名和解析进度 |
