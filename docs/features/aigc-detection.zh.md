# 降 AIGC 率

深度研值独家中文降 AIGC 引擎，帮你解决论文提交前最焦虑的问题——AI 痕迹检测。

## 核心技术

| 技术 | 说明 |
|------|------|
| **21 组 AI 热词自动替换** | 自动识别并替换「在当今时代」「值得注意的是」「此外」等 AI 高频用词 |
| **Best-of-N 改写策略** | 为每段内容生成多个改写版本，自动选最优 |
| **场景感知 humanize** | 根据上下文（学术论文/竞赛报告/课程作业）调整改写风格 |

## 使用步骤

1. **输入待改写内容**
2. **选择改写场景**
3. **获取改写结果**

## 示例 Prompt

```text
请对以下段落进行降 AIGC 处理，场景是学术论文，保持学术严谨性的同时降低 AI 检测率。
```

```text
帮我改写这篇文献综述的第三部分，去除明显的 AI 痕迹，保持原意不变。
```

```text
对上传的论文全文做降 AIGC 优化，这是毕业论文，要求语言自然、符合中文学术写作习惯。
```

> 实测效果：AIGC 检测率从 **85%** 降至安全线以下。学术模式下写作自动启用降 AIGC 优化。

> 降 AIGC 功能是辅助手段，建议在 AI 输出基础上加入个人观点和修改，效果更佳。
