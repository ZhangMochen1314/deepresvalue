# Data Analysis

> 🚧 This page is under construction. For the complete English guide, see [user-guide.en.md](../user-guide.en.md).

## Overview

Upload your data (CSV, Excel, Stata, SAS, PDF, Word, 80+ formats) and describe your analysis needs in Chinese. AI automatically selects optimal methods from 100+ statistical and ML techniques, writes Python/R code, executes it, and outputs journal-standard tables and charts.

## Supported Methods

| Category | Examples |
|----------|----------|
| Traditional Econometrics | DID, IV, RDD, Synthetic Control, Panel FE |
| Causal ML | DML, Causal Forest, Meta-learner |
| Statistical Tests | Descriptive stats, correlation, t-test, ANOVA |
| Machine Learning | Random Forest, XGBoost, Neural Networks, PCA |
| Survival Analysis | Kaplan-Meier, Cox Proportional Hazards |
| Spatial Econometrics | Moran's I, GWR, Spatial Weight Matrix |
