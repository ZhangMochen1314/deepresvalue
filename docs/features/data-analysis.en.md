# Data Analysis

DeepResValue's most core capability — upload your data, describe your analysis needs in Chinese, and the AI handles the entire workflow from method selection to result output.

## How It Works

Upload your data (supporting Excel, CSV, PDF, Word, Stata, SAS, SQLite, and 80+ other formats), then describe your analysis needs in Chinese. The AI will:

1. Automatically understand your research intent
2. Match the optimal method from **100+ statistical and machine learning techniques**
3. Write Python or R code and execute it
4. Output journal-standard three-line tables, regression tables, and visualizations

## Supported Analysis Methods

| Category | Example Methods |
|----------|----------------|
| Traditional Econometrics | DID (Difference-in-Differences), IV (Instrumental Variables), RDD (Regression Discontinuity), Synthetic Control, Panel Fixed Effects |
| Causal Machine Learning | DML (Double Machine Learning), Causal Forest, Meta-learner, Neural Causal |
| Statistical Tests | Descriptive statistics, correlation analysis, t-test, ANOVA, chi-square test |
| Machine Learning | Random Forest, XGBoost, Neural Networks, Clustering, PCA |
| Survival Analysis | Kaplan-Meier curves, Cox Proportional Hazards, Competing Risks Models |
| Spatial Econometrics | Spatial Weight Matrices, Moran's I, Geographically Weighted Regression (GWR) |
| Text Analysis | BERT/LLM text classification, Sentiment Analysis, Topic Modeling |

## Step-by-Step Usage

1. **Upload your data file** — Click the attachment button to the left of the input box, or drag and drop files directly into the input area. Supports CSV, Excel, Stata (.dta), and 80+ other formats.
2. **Describe your analysis needs** — In the chat box, enter your specific analysis requirements in Chinese, including the method you want to use, variables to control, etc.
3. **View analysis results** — The AI executes the analysis automatically and generates three-line tables, regression tables, and visualization charts. All results can be downloaded from the right-side file panel.
