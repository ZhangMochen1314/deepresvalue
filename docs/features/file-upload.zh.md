# 文件上传

深度研值支持 **11 大类 90+ 种文件格式**上传，覆盖全学科科研数据需求，AI 可跨文件综合分析与对比。

## 支持的文件格式

| 类型 | 格式 |
|------|------|
| 📊 统计/数据 | `.csv` `.xlsx` `.xls` `.dta` `.sav` `.zsav` `.tsv` `.json` `.sas7bdat` `.xpt` `.por` `.parquet` `.feather` |
| 🔬 科研数据 | `.h5` `.hdf5` `.mat` `.RData` `.rds` `.nc` |
| 📄 文档文件 | `.pdf` `.doc` `.docx` `.txt` `.md` |
| 🖼️ 图片文件 | `.png` `.jpg` `.jpeg` `.gif` `.svg` `.webp` `.tif` `.tiff` |
| 📦 压缩包 | `.zip` `.rar` `.7z` `.tar.gz` |
| 💻 脚本/代码 | `.py` `.R` `.do` `.Rmd` `.sql` `.sas` `.ipynb` `.m` `.jl` `.nb` |
| 🌍 空间/遥感 | `.shp` `.shx` `.dbf` `.prj` `.qpj` `.geojson` `.kml` `.gpx` `.gpkg` `.hdr` `.img` `.asc` `.dem` |
| 🧬 生物信息 | `.fasta` `.fastq` `.vcf` `.sam` `.bed` `.gff` `.pdb` `.cif` `.mol` `.sdf` |
| 📚 文献引用 | `.bib` `.ris` `.enw` |
| 📝 LaTeX 源码 | `.tex` `.cls` `.sty` `.bst` |
| 🏗️ CAD/工程 | `.dxf` `.stl` `.obj` `.ply` `.glb` `.gltf` `.3mf` `.off` `.idf` `.epw` `.tcl` |

## 上传步骤

1. **添加文件**
2. **确认文件标签**
3. **发送分析请求**

## 产出文件

AI 在分析过程中生成的文件（报告、图表、代码等）会显示在 **主对话区右侧的文件面板** 中：

- 点击文件名可 **预览** 内容
- 点击 **下载** 按钮保存到本地
- 生成的图表支持放大查看和下载为 PNG 格式
> 支持一次上传多个文件，AI 可以跨文件综合分析与对比。单个文件最大支持 **100MB**。

> 单次对话最多上传 **10 个文件**。如需处理超大文件，建议先分割或压缩后再上传。上传前精简文件可有效降低积分消耗。
