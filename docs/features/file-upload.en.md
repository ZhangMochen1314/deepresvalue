# File Upload

DeepResValue supports **11 categories and 90+ file formats**, covering data needs across all academic disciplines. The AI can perform cross-file comprehensive analysis and comparison.

## Upload Steps

1. **Add files** — Click the **📎 attachment button** to the left of the input box, or **drag and drop** files directly into the input area.
2. **Confirm file tags** — After upload, file tags appear above the input box. Click **×** on a tag to remove that file.
3. **Send analysis request** — Enter your analysis needs and press Enter. The AI automatically reads and analyzes the uploaded files.

## Output Files

Files generated during AI analysis (reports, charts, code, etc.) appear in the **file panel to the right of the main chat area**:

- Click a filename to **preview** the content
- Click the **download** button to save locally
- Generated charts support zoom viewing and PNG download

### Supported Preview Formats

| File Type | Preview Method |
|-----------|---------------|
| PDF documents (.pdf) | Built-in PDF reader with zoom and page navigation |
| Office documents (.docx .xlsx .pptx) | Online preview preserving original formatting |
| Code & data (.csv .json .txt .py .R .md .do .sql .sas) | Syntax-highlighted code preview |
| Images (.png .jpg .svg .webp .tif) | Direct display with zoom support |
| Spatial data (.geojson) | Interactive map preview |

> You can upload multiple files at once; the AI performs cross-file comprehensive analysis and comparison. Maximum single file size: **100MB**.

> Maximum **10 files per conversation**. For oversized files, consider splitting or compressing before upload. Streamlining files before upload effectively reduces credit consumption.
