# 排版功能

深度研值内置 LaTeX 排版引擎，生成期刊标准的专业图表和文档，直接复制进论文。

## 功能特点

- **LaTeX 排版引擎驱动**：生成期刊标准的专业图表
- **多种学术图表**：三线表、回归表、结构方程图、事件研究图——直接复制进论文
- **多格式导出**：导出 PDF / Word / LaTeX 源码，投稿格式一键达标
- **专业科研绘图**：内置 DeepResValue-SciPlot 绘图技能，覆盖 20+ 学术图表类型

## 支持的图表类型

| 类别 | 图表示例 |
|------|----------|
| 统计图表 | 散点图、热力图、箱线图、小提琴图 |
| 学术图表 | 森林图、漏斗图、事件研究图 |
| 结构图 | 路径分析图、结构方程图、社会网络图 |
| 专业图表 | 脑区激活图、基因表达热图、地理空间图 |

## 使用步骤

1. **完成数据分析**
2. **指定排版需求**
3. **获取排版输出**
