# 校园大使计划

深度研值正在全国高校招募校园大使——帮助更多同学告别编程恐惧、搞定论文竞赛。

## 大使权益

| 权益 | 说明 |
|------|------|
| 全功能内测 | 129 位科研领域专家、对话模式、多源数据搜集提前畅享，免排队 |
| 推广支持 | 专属推广物料包 + 海报模板 + 文案素材，轻松在班级群、社交平台、社团宣传 |
| 荣誉认证 | 颁发 DeepResValue 校园大使证书，优秀大使可获推荐信，简历加分 |

## 如何加入

1. **官网申请** — 访问平台官网，在「校园大使」入口填写学校与身份信息提交申请。
2. **获取资格** — 审核通过后，开通内测资格与大使权益。
3. **开始推广** — 使用专属物料在校园内推广，帮助更多同学了解深度研值。

> 校园大使面向全国所有高校在读学生，无专业限制，欢迎各学科同学加入。
