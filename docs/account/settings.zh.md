# 账户设置

在账户设置中，你可以管理个人信息和查看邀请码等内容。

## 进入设置

点击侧边栏底部的**头像区域**即可进入用户设置页面。

## 可修改项目

| 设置项 | 说明 |
|--------|------|
| 昵称 | 设置你的显示名称 |
| 头像 | 上传自定义头像 |
| 手机号 | 更换绑定的手机号 |

## 积分余额

- 顶栏右侧实时显示当前积分余额
- 点击积分显示区域可查看详细的消费记录

## 主题切换

平台提供四种界面主题，点击侧边栏左侧的主题按钮即可切换：

| 主题 | 风格 | 适用场景 |
|------|------|----------|
| 暖色 | 米色暖调，柔和对比 | 长时间阅读，护眼 |
| 深蓝暗调 | 经典暗色配色 | 低光环境 |
| 浅色 | 中性蓝白，清晰明亮 | 通用日常 |
| 暗色 | 冷灰蓝深色背景 | 夜间使用 |

> 主题切换即时生效，无需刷新页面。
