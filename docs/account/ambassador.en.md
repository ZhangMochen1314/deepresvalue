# Campus Ambassador Program

DeepResValue is recruiting campus ambassadors from universities nationwide — help more students overcome coding anxiety and ace their papers and competitions.

## Ambassador Benefits

| Benefit | Description |
|---------|-------------|
| **Full Beta Access** | All 100+ professional skills, conversation modes, multi-source data collection — early access, no queue |
| **Promotion Support** | Exclusive promotion material package + poster templates + copy assets for easy sharing in class groups, WeChat Moments, and clubs |
| **Honor Certification** | DeepResValue Campus Ambassador certificate issued; outstanding ambassadors receive recommendation letters for resume enhancement |

## How to Join

1. **Add WeChat** — Add WeChat **MoChen11-20**, note: "Ambassador + University Name".
2. **Get qualified** — After review, receive beta access and ambassador benefits.
3. **Start promoting** — Use exclusive materials to promote on campus, helping more students learn about DeepResValue.

> The Campus Ambassador program is open to all currently enrolled university students regardless of major. Students from all disciplines are welcome to join.
