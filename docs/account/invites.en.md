# Invite & Earn

Invite friends to register on DeepResValue — both you and the invitee earn credit rewards for a win-win outcome.

## Reward Rules

| Role | Reward | Description |
|------|--------|-------------|
| 🎁 **Inviter** | **+200 credits** | Credited automatically when your invite code is successfully used for registration |
| 🆕 **Invitee** | **+100 credits** | Automatically received as a new-user bonus after registering with an invite code |

## How to Invite

1. **Get your invite code** — Enter the user settings page and locate your unique invite code.
2. **Share the invite code** — Share it with lab members, classmates, or friends.
3. **Friend registers** — The invitee enters your invite code during registration.
4. **Credits arrive** — After successful registration, credits are automatically credited to both parties.

> Share with lab members and classmates — not only helping them overcome the entry barrier, but also earning generous credit rewards for yourself. There is no limit on the number of invitees.

## View Your Invite Code

The invite code can be found in the user settings page. Click the avatar area at the bottom of the sidebar to access settings.

> Each invite code can only be used when an invitee registers for the first time. Existing accounts cannot retroactively apply an invite code.
