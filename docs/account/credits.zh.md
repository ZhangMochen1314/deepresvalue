# 积分系统

深度研值采用积分制控制 AI 资源消耗，合理使用积分可以最大化你的科研产出。

## 积分消耗规则

| 维度 | 说明 |
|------|------|
| 文件大小 | 上传的文件越大，消耗积分越多 |
| 文件数量 | 一次上传多个文件会叠加消耗，单次对话最多 10 个文件 |
| 问题复杂度 | 分析需求越复杂（多步骤推理、多维交叉分析），消耗越多 |
| 工具调用 | 涉及联网搜索、数据库查询等额外工具调用时，会增加消耗 |

## 积分获取方式

| 方式 | 积分数量 | 说明 |
|------|----------|------|
| 新用户注册 | 系统赠送 | 首次注册自动获得初始积分 |
| 邀请好友 | +500 | 你的邀请码被他人成功注册使用 |
| 被邀请注册 | +200 | 使用他人邀请码注册成功 |

## 省积分技巧

> 以下方法可以有效降低积分消耗：
> - 上传前精简文件——去掉无关列、只保留分析需要的观测值
> - 一次把需求说清楚，避免反复追问导致重复消耗
> - 单文件上限 100MB，合理控制数据范围
> - 建议合并同类数据后再上传，减少文件数量
