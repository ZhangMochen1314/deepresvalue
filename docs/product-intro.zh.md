> **让科研回归本质，让工具服务于思想，让创造不被重复所困。**

## 一句话简介

**DeepResValue（深度研值）** 是面向全学科科研工作者的 AI 科研助手——**零安装零配置，打开网页即得满配科研环境**，用中文一句话驱动，自动写码分析、检索文献、排版论文。手机、平板、电脑三端互通，随时随地开展科研。前沿科研分析方法全覆盖，没有做不了的科研分析方法——Agent 实时在对应领域专家指导下写代码、云端执行。

## 核心能力

### 零配置满配环境

四大计算内核（Python / R / MATLAB-Octave / SPICE-ngspice）+ Word / LaTeX 排版引擎全部**云端预配置**，用户无需任何安装配置，打开网页应用即得满配环境。**手机、平板、电脑三端统一账号、数据互通、随意切换**，均具备满配能力。

### 四大计算内核

| 内核 | 说明 |
|------|------|
| **Python 执行内核** | 核心分析引擎，覆盖 100+ 统计与机器学习方法 |
| **R 执行内核** | 补充统计分析能力，支持 R 原生包调用 |
| **MATLAB 脚本执行** | `.m` 脚本经 Octave 兼容执行，覆盖自动化/电子/控制类场景 |
| **SPICE 电路仿真** | 经 ngspice 执行电路仿真，支持电子工程类课程与竞赛 |

### Word + LaTeX 排版引擎

- LaTeX 排版引擎生成期刊标准专业图表（三线表、回归表、结构方程图等）
- 支持导出 **PDF / Word / LaTeX 源码**，投稿格式一键达标
- 内置 DeepResValue-SciPlot 绘图专家，覆盖 20+ 学术图表类型
- **云端预配置，开箱即用**——无需本地安装 TeX 发行版或 Office

### MCP 外部连接器

通过 Model Context Protocol 直接调用第三方专业数据源——**已集成数十个 MCP 连接器，且持续扩张中**：

| 连接器 | 类型 | 说明 |
|--------|------|------|

| **北大法宝** | 法律检索 | 中国法律法规、司法案例、学术期刊检索 |
| **万得 Wind** | 金融数据 | 上市公司财务、宏观经济、行业数据 |

| **企查查** | 企业信息 | 工商注册、风险信息、知识产权、经营数据、历史变更 |
| **百度 AI 学术搜索** | 学术检索 | AI 驱动的学术文献智能搜索 |

### BYOK 自接 LLM

支持 Bring Your Own Key，接入 DeepSeek、OpenAI 或任何 OpenAI 兼容 API。平台仅收取隔离环境执行基础积分，模型费用由用户自行承担。

### 中文驱动 + 严谨可溯源

- 全中文交互，说出分析需求即可自动完成全流程
- 129 位科研领域专家自动匹配；每位专家是对应领域的专业工作流和工具组合包
- **前沿科研分析方法全覆盖**——没有做不了的科研分析方法，Agent 实时在对应领域专家指导下写代码、云端执行
- 各类科研数据内置，只需说需求 Agent 自主调用
- 每一步分析保留完整代码与执行日志，满足学术规范要求

| 领域 | 能力示例 |

| **管理学与营销** | 结构方程模型 SEM、量表信效度（Cronbach's α / CFA）、中介调节效应、多层 HLM、实验设计（RCT/准实验）、营销计量 |

| **流行病学与公共卫生** | 队列/病例对照研究、Meta 分析、竞争风险模型（Cox/Fine-Gray）、倾向评分匹配 PSM、公共卫生大数据 |
| **生信分析** | 基因组/转录组/蛋白组差异分析、富集分析（GO/KEGG）、NGS 测序数据分析 |
| **贝叶斯统计** | 贝叶斯推断、MCMC（Stan/PyMC）、分层贝叶斯模型、贝叶斯网络、贝叶斯优化 |
| **机器学习与 AI** | 深度学习（CNN/RNN/Transformer）、NLP 文本挖掘、计算机视觉、模型可解释性（SHAP/LIME）、大模型科研应用 |
| **环境科学与能源** | 空间计量（SAR/SEM/SDM、莫兰指数、GWR）、碳排放面板、碳核算与双碳研究、环境库兹涅茨曲线 |
| **空间地理** | 空间权重矩阵、空间自相关、GeoJSON 行政区划、遥感与 GIS 空间分析、地图可视化 |
| **社会科学** | 质性编码辅助、问卷数据分析、社会网络图、文本情感分析 |
| **健康医学** | NHANES/BRFSS 等 CDC 公开数据、MeSH 术语、NCBI 基因信息 |
| **人文社科** | 文献综述生成、学术写作润色、降 AIGC 检测率、论文全流程辅助 |
| **土木/机械/自动化** | 结构力学与有限元分析、机械仿真、控制系统（PID/状态空间）、电子电路与 PCB 设计、信号处理 |
| **农业科学** | 农业经济学、遥感与 GIS 空间分析、环境与资源经济分析 |
| **工科计算** | MATLAB 脚本执行、SPICE 电路仿真、CAD/工程文件分析、计算机辅助设计 |
| **数学建模** | 全国大学生数学建模竞赛（CUMCM）、美国大学生数学建模竞赛（MCM/ICM）全流程辅助 |
