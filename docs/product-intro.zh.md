# DeepResValue 深度研值 — 产品介绍

> **让科研回归本质，让工具服务于思想，让创造不被重复所困。**

---

## 一句话简介

**DeepResValue（深度研值）** 是面向全学科科研工作者的 AI 科研助手——用中文一句话驱动，自动写码分析、检索文献、排版论文，让不懂编程的研究者也能完成专业级科研任务。

---

## 科研群体痛点与解决方案

| 痛点 | 深度研值的方案 |
|------|---------------|
| 🔴 **代码与统计门槛高** | 中文一句话驱动，AI 自动写码执行——零编程即可完成 DID、DML、RDD 等前沿方法分析 |
| 🔴 **工具链割裂** | 一站式完成检索 → 分析 → 写作 → 排版，无需在 Stata、SPSS、Word、LaTeX 之间反复切换 |
| 🔴 **数据获取难** | 预置 6 套面板数据（城市/省级/县域/上市公司）+ 100+ 技能驱动多源数据搜集 |
| 🔴 **分析不可复现** | 全程保留完整代码与执行日志，100% 可追溯可复现，答辩时直接展示证据链 |
| 🔴 **排版耗时费力** | Word + LaTeX 专业排版引擎，一键导出 PDF/Word/LaTeX 源码，投稿格式快速达标 |
| 🔴 **语言与表达门槛** | 全中文交互界面，内置降 AIGC 检测率引擎，论文安心提交 |

## 核心能力

### 四大计算内核

| 内核 | 说明 |
|------|------|
| **Python 执行内核** | 核心分析引擎，覆盖 100+ 统计与机器学习方法 |
| **R 执行内核** | 补充统计分析能力，支持 R 原生包调用 |
| **MATLAB 脚本执行** | `.m` 脚本经 Octave 兼容执行，覆盖自动化/电子/控制类场景 |
| **SPICE 电路仿真** | 经 ngspice 执行电路仿真，支持电子工程类课程与竞赛 |

### Word + LaTeX 排版引擎

- LaTeX 排版引擎生成期刊标准专业图表（三线表、回归表、结构方程图等）
- 支持导出 **PDF / Word / LaTeX 源码**，投稿格式一键达标
- 内置 DeepResValue-SciPlot 绘图技能，覆盖 20+ 学术图表类型

### MCP 外部连接器

通过 Model Context Protocol 直接调用第三方专业数据源：

| 连接器 | 类型 | 说明 |
|--------|------|------|
| 北大法宝 | 法律检索 | 中国法律法规、司法案例、学术期刊检索 |
| 万得 Wind | 金融数据 | 上市公司财务、宏观经济、行业数据 |
| 更多连接器 | 持续扩展 | 威科先行、百度网盘等即将开放 |

### BYOK 自接 LLM

支持 Bring Your Own Key，接入 DeepSeek、OpenAI 或任何 OpenAI 兼容 API。平台仅收取沙箱执行基础积分，模型费用由用户自行承担。

### 中文驱动 + 严谨可溯源

- 全中文交互，说出分析需求即可自动完成全流程
- 100+ 专业科研技能自动匹配
- 每一步分析保留完整代码与执行日志，满足学术规范要求
