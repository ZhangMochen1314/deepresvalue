## 2. 为什么选择深度研值

### 🏛️ 权威引擎

搭载前沿大模型，具备百万级 Token 深度上下文理解能力。不是简单的聊天机器人——它能真正理解你的研究问题，自主选择最优分析方法，生成专业级结果。

### 🔍 完全可复现

每一步分析都保留 **完整 Python 代码与执行日志**。分析全程可追溯，满足学术规范要求。

> 这是很多同学选择深度研值的核心原因——可追溯，才安心。

内置城市/省份/县域宏观面板与上市公司财务、治理面板数据；数据搜集专家还可接入金融行情、健康、医学、生物、文献等外部数据源。用中文一句话描述需求，AI 精准返回结构化数据，**数据获取更便捷、更可靠**。

不需要学编程语言，不需要懂统计公式。用中文说出你的分析需求，同时支持 **Python 和 R** 双分析引擎，并可直接运行 MATLAB 脚本（.m）与 SPICE 电路仿真，AI 自动选方法、写代码、跑回归、出三线表。**注册即用，3 分钟上手**。前沿科研分析方法全覆盖——没有做不了的科研分析方法，Agent 实时在对应领域专家指导下写代码、云端执行。

四大计算内核（Python / R / MATLAB-Octave / SPICE-ngspice）+ Word / LaTeX 排版引擎全部**云端预配置**，用户无需任何安装配置，打开网页应用即得满配环境。**手机、平板、电脑三端统一账号、数据互通、随意切换**，均具备满配能力。

## 5. 输入框功能面板

在主对话页面的输入框上方，有一排**功能切换按钮（药丸按钮）**，让你在发送消息前快速调整 AI 的行为模式：

### 5.1 专注模式 🎯

**专注模式是深度研值的「自动驾驶」模式**——先规划，后执行，AI 自主拆解复杂任务并逐步完成。默认关闭，需要时手动开启。

**核心特点：**

| 特点 | 说明 |
|------|------|
| 🧠 **先规划后执行** | AI 收到任务后会先生成完整的执行计划，展示步骤拆解，经你确认后再逐步执行 |
| 📋 **多步工作流** | 适合需要多阶段协作的复杂任务（如「帮我完成论文全流程：文献综述 → 数据分析 → 结果讨论 → 格式排版」） |
| 🔍 **过程完全透明** | 每一步子任务的思考链、工具调用、代码执行日志全部可见，随时可展开查看 |
| ⏸️ **可随时干预** | 在计划阶段可以调整步骤顺序或跳过不必要环节，AI 实时适配 |

**何时开启专注模式？**
- ✅ 复杂多步骤任务（如完整论文写作、项目申报书撰写、竞赛报告全流程）
- ✅ 需要严密的逻辑推理链（如理论推导、方法论证）
- ✅ 希望看到完整的执行计划再动手
- ❌ 简单问答（如「什么是 DID」「帮我翻译这段话」）不需要开启

**与普通模式的区别：**

| | 普通模式 | 专注模式 |
|---|---------|---------|
| 执行方式 | 直接执行，边想边做 | 先生成计划 → 确认 → 逐步执行 |
| 适用任务 | 单一任务、快速问答 | 复杂多阶段任务 |
| 透明度 | 工具调用可见 | 计划 + 工具调用 + 子任务卡片全可见 |

> 💡 **技巧**：开启专注模式后，AI 会先生成一个「任务计划书」，你可以说「第一步跳过」「增加一个质量检查步骤」来调整计划，然后说「确认执行」开始。

### 5.2 深度思考 💎

**默认开启**，AI 在回答前自动进行深度推理。启用深度推理链，AI 在回答前进行深层次分析，适用于复杂逻辑推理和数学分析。

- **工作原理**：AI 在给出最终答案前，先进行多轮内部推理（Chain-of-Thought），拆解问题结构
- **适用场景**：理论推导、数学建模、复杂统计方法选择、因果推断设计
- **视觉效果**：激活后按钮呈现辉光效果，推理过程以折叠面板形式展示

> ⚠️ 深度思考会增加响应时间（约 1.5x ~ 3x），简单问题不建议开启。

### 5.3 联网搜索 🌐

**默认开启**，AI 回复时自动检索最新信息。实时检索最新信息与学术文献，确保 AI 的回答包含最新数据和研究动态。

- **搜索范围**：中文 + 英文数据库，包括学术期刊、预印本、统计数据源
- **引用溯源**：搜索结果标注来源链接，回复中显示上标标记（如 `[1]`、`[2]`），点击可查看详情
- **适用场景**：查找最新文献、验证数据时效性、追踪研究前沿

> 💡 搜索过程中，主对话区右侧会显示**搜索面板**，实时展示检索到的来源数量和摘要。

### 5.4 模式选择器 🎭

在输入框上方，你可以随时切换 AI 的**对话风格**（详见[第 4 节](#4-三种使用模式)）：

| 模式 | 图标 | 适用场景 |
|------|------|----------|
| **通用** | — | 默认模式，不受特定风格约束，自由对话 |
| **导师模式** | 🎓 | 学术顾问式引导，推荐方法、评估可行性 |
| **学术模式** | ✨ | 论文写作一条龙，文献综述、开题、答辩 |
| **专业助手** | 🚀 | 专业数据分析，类似 Stata/R 级别的输出 |

> 💡 不选择模式时使用**通用模式**，AI 会自行判断最合适的回应风格。

### 5.5 文件管理 📁

点击输入框上方的**文件管理**按钮，可查看当前对话关联的所有文件：

- **上传文件**：你上传的数据文件、文档等
- **产出文件**：AI 分析过程中生成的图表、报告、代码等

支持在线预览和一键下载，方便你随时查看和复用文件。

> 💡 文件管理按钮只在有文件关联时显示，新对话中不会出现。

### 5.6 性能模式 ⚡

**性能模式是你控制积分消耗的「油门」**——根据任务复杂度选择合适的档位，既能保证效果，又能节省积分。

点击输入框上方的**性能模式切换按钮**（默认显示「⚡ 极致模式」），展开下拉菜单选择档位：

| 模式 | 图标 | 适合场景 | 说明 |
|------|------|----------|------|
| ⚡ **极致模式** | ⚡ | 复杂分析、论文写作、数学建模 | 科研火力全开，能力最完整，适合复杂任务（默认档） |
| 🚀 **性能模式** | 🚀 | 日常问答、简单查询、思路探讨 | 速度快、积分省一半，简单任务够用 |
| 🪶 **经济模式** | 🪶 | 概念问答、闲聊、快速检索 | 纯聊天最省，积分花得最少、响应最快 |

**各档位差异：**

| 维度 | ⚡ 极致模式 | 🚀 性能模式 | 🪶 经济模式 |
|------|------------|------------|------------|
| 提示词完整度 | 完整科研规范 | 精简版 | 最精简 |
| 工具调用能力 | 全部工具可用 | 核心工具可用 | 基础对话，复杂任务自动加载完整规范 |
| 适合任务 | 多步骤分析、论文写作 | 单一问题、简单分析 | 概念问答、思路探讨 |
| 积分消耗 | 基准 | 约省一半 | 最少 |

**如何切换？**

1. 点击输入框上方的**性能模式按钮**（显示当前模式图标和名称）
2. 在下拉菜单中选择目标档位
3. 切换即时生效，**同一对话中可随时切换**

> 💡 **选择建议**：心里没底就选极致模式（默认）；日常简单问答切性能模式省钱；纯聊天用经济模式。遇到复杂分析/论文/建模时建议切回极致模式，确保输出质量。

## 6. 核心功能详解

### 6.1 自然语言数据分析

**这是深度研值最核心的能力。**

上传你的数据文件（支持 CSV、Excel、Stata、SAS、PDF、Word 等 80+ 格式），用中文描述分析需求。AI 会：

1. 自动理解你的研究意图
2. 从 **100+ 统计与机器学习方法** 中匹配最优方案
3. 自动选择 Python 或 R 编写代码并执行
4. 输出期刊标准的三线表、回归表、可视化图表

支持的分析方法（部分）：

| 类别 | 方法示例 |
|------|----------|

## 12. 常见问题

### Q1：专注模式适合什么时候使用？

专注模式采用「先规划后执行」策略，适合需要多步骤协调的复杂任务。当你需要 AI 完成包含多个阶段的复杂任务时（如完整的论文写作流程、项目申报书撰写、竞赛报告全流程），开启专注模式可以让 AI 先生成完整的执行计划供你审核，确认后再逐步执行。每步过程完全透明，随时可以干预调整。

简单问答、翻译、单一分析任务则不需要开启专注模式，普通模式即可快速完成。

---

### Q2：深度思考、联网搜索、专注模式可以同时开启吗？

**可以。** 三个功能可独立开启/关闭，互不冲突：

- 专注模式 + 深度思考：复杂任务先规划，每步都经过深度推理——适合高难度方法论研究
- 专注模式 + 联网搜索：复杂任务按计划执行，每步实时检索最新文献——适合文献综述和前沿追踪
- 深度思考 + 联网搜索：单一问题深度推理同时检索外部信息验证——适合方法选择和技术验证

> ⚠️ 三个功能同时开启时，每次响应时间会显著增加，建议按需组合。

---

### Q3：我不会编程，真的能用吗？

**完全可以。** 深度研值的设计理念就是「零代码」。你只需要用中文说出分析需求，AI 自动完成选方法、写代码、跑分析、出图表的全过程。平台的核心用户就是不懂编程的本科生。

---

### Q4：AI 生成的结果可靠吗？满足学术规范吗？

**可靠。** 深度研值搭载前沿大模型。最关键的是，**每一步分析都保留完整代码和执行日志**——分析全程可追溯，满足学术规范要求。

---

### Q5：没有数据怎么办？

平台预置城市/省份/县域宏观面板与上市公司面板数据，数据搜集专家还可接入金融行情、健康、医学、生物、文献等外部数据源。用中文一句话描述需求，AI 精准返回结构化数据。数据获取更便捷、更可靠。

---

### Q6：上传的文件有大小限制吗？

单个文件最大支持 **100MB**，单次对话最多上传 **10 个文件**。文件格式不限制，仅视频类文件（`.mp4` `.mov` `.avi` 等）暂不支持上传。如需处理超大文件，建议先分割或压缩后再上传。

---

### Q7：AI 的表达痕迹太重怎么办？

深度研值内置**降 AIGC 检测率专家**：采用「定位→诊断→改写→自评→复查」五步闭环工作流，系统消除中文 17 类 + 英文结构化 AI 写作痕迹，覆盖知网 AMLC、万方、维普、Turnitin、GPTZero 五大检测器。在对话中说「帮我降低 AIGC 检测率」即可触发。

---

### Q8：AI 回复中断了怎么办？

可尝试以下步骤：
1. 在 AI 回复过程中，你也可以随时点击输入框右侧的 **停止按钮** 主动中断生成
2. 中断或意外截断后，在输入框中发送 **「请继续」**，AI 会从断点继续生成
3. 刷新页面后重新打开该对话，大部分情况下历史结果已保存
4. 如反复出现问题，请通过官网反馈渠道联系技术支持

### Q13：分析任务运行很久、会不会白等？

不会。如果某次分析计算量较大、接近系统单次运行的时间上限，深度研值会**尽量返回已经完成的部分结果**（例如已算出的中间结论、已搜集到的部分文献），而不是直接失败丢弃。你可以基于这些部分结果继续追问，或让 AI 从中断处继续。若任务本身偏重（如大规模建模、大批量文献搜集），建议拆分为更小的步骤分次进行。

---

### Q14：极致模式、性能模式、经济模式有什么区别？该怎么选？

三档模式的**核心区别在于提示词的完整度**，直接影响 AI 的响应质量和积分消耗：

- **极致模式**（默认）：完整科研规范，适合复杂分析、论文写作、数学建模——「心里没底就选它」
- **性能模式**：精简版规范，速度快、积分省约一半——适合日常问答和简单查询
- **经济模式**：最精简，积分花得最少、响应最快——适合概念问答和闲聊

切换方式：点击输入框上方的**性能模式按钮**，在下拉菜单中选择。同一对话中可随时切换，即时生效。

> 💡 需要跑代码、查资料、写论文时，经济模式也会自动加载完整规范，能力不打折。放心用。

外部连接器（MCP）让你在对话中直接调用第三方专业数据源（如智慧芽 PatSnap、北大法宝、万得 Wind、同花顺 iFinD、企查查、百度 AI 学术搜索等），无需离开平台。平台已接入**数十个 MCP 连接器**，覆盖专利与知识产权、法律检索、金融数据、企业信息、学术搜索、地理服务、量化行情等领域。使用方式：

**平台不额外收取 MCP 连接器的服务费**，你只需承担第三方数据源本身的调用费用（如有）。你的 Token 采用加密存储，可随时停用或解绑吊销。

3. 在弹窗中填入你自己的 API Token（**BYOK，自己持有凭证**）
4. 点击 **「保存并启用」**——系统自动做连通性验证
   - ✅ 绿色「连接成功（N 个工具）」= 启用成功
   - ❌ 红色提示 = 连接失败，按提示排查

**使用方式：**

启用后，在对话中直接对 AI 说：
- 「用北大法宝检索关于数据安全法的最新司法解释」
- 「用 Wind 查贵州茅台近 5 年的财务指标」
- 「用北大法宝对比分析两则相似案例的判决差异」

AI 会自动调用对应连接器完成检索，结果以结构化方式呈现在对话中。

**安全与隐私：**

- 你的 Token/凭证采用 **Fernet 加密存储**，仅回显最后 4 位（如 `****abcd`）
- 凭证仅用于对应第三方代理调用，**不会被平台用于其他用途**
- 你可以随时**停用或解绑吊销**凭证
- 建议定期更换 Token，确保账号安全

> 💡 外部连接器是**平台免费功能**，不额外收取服务费。但第三方数据源本身可能有调用限制（如 Wind 的并发数限制），具体以第三方服务条款为准。

### 14.2 接入你自己的模型（BYOK）

**什么是 BYOK？**

BYOK（Bring Your Own Key）让你使用自己的 LLM API Key 接入对话功能。接入后，对话将使用你的模型与额度，**平台仅收取云端隔离沙箱执行与时间积分**，不收取额外的模型调用费用。

> 💡 **为什么用 BYOK？** 如果你有自己的 DeepSeek / OpenAI / 其他兼容 API Key，可以直接接入使用，不受平台模型配额限制。

**支持的协议：**

- ✅ **OpenAI 兼容协议（HTTPS）**——覆盖 DeepSeek、OpenAI、Moonshot、智谱 GLM、通义千问等主流服务
- ❌ 不支持 HTTP（安全要求）

**如何添加模型配置？**

1. 打开 **设置** → **模型设置** 页面
2. 点击 **「添加模型配置」**
3. 填写核心三要素：
   - **接口地址**：API 的 Base URL（如 `https://api.deepseek.com/v1`）
   - **API 密钥**：你的 API Key（如 `sk-...`）
   - **模型名称**：模型标识（如 `deepseek-chat`）
4. 勾选模型能力（可选）：
   - 「支持深度思考」——模型可输出思维链推理
   - 「支持推理等级」——对话中可选 Off / High / Max 三档
5. 点击 **「测试连接」** 验证配置是否正确
6. 测试通过后点击 **「添加模型配置」** 保存

**管理我的模型：**

| 操作 | 说明 |
|------|------|
| **测试** | 验证已保存的模型配置是否正常连接 |
| **编辑** | 修改接口地址、模型名称或能力声明，保存后立即生效 |
| **设为默认** | 选择默认模型后，新对话自动使用该模型 |
| **删除** | 删除不需要的模型配置（不可恢复） |

**安全与隐私：**

- API 密钥**不回显**（编辑时留空表示不修改），服务端加密存储
- 你可以随时删除配置，密钥立即从平台移除
- 平台**不会**使用你的 API Key 做任何对话之外的用途

> 💡 BYOK 是**平台免费功能**，不额外收取服务费。使用自有模型时，仅按对话消耗的云端隔离沙箱执行时间和工具调用收取基础积分，模型调用费用由你自行承担（由你的 API 提供商计费）。
