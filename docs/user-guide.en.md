## 3. Quick Start

### Registration & Login

1. Visit [deepresvalue.top](https://deepresvalue.top).
2. Click **"Get Access"** or **"Login"** in the top-right corner.
3. Register with your **phone number**: enter your number and SMS verification code.

> 💡 New users automatically receive initial credits for immediate full-feature access.

### First-Time Onboarding

After registration, guided cards walk you through core features (shown only once, skippable):

- **Desktop**: 4 steps covering input box, mode switching, skill panel, and conversation sidebar
- **Mobile**: 3 steps covering input box, credit rules, and skill selection

### Interface Overview

| Area | Location | Main Functions |
|------|----------|---------------|
| **Left Sidebar** | Left side of screen | Conversation list, global search, folder management, theme switching |
| **Main Chat Area** | Center of screen | Message input (with feature panel), AI responses, file panel |
| **Top Bar** | Top of screen | Current conversation title, credit balance, account settings |

### Creating Your First Conversation

1. Click the **"+ New Conversation"** button at the top of the sidebar.
2. Type your question or task in the bottom input box and press **Enter**.
3. AI begins analysis and returns results in a streaming fashion.

> 💡 **Tip**: More specific prompts yield better results. For example:
> - ❌ Vague: "Help me do an analysis"
> - ✅ Specific: "Use DID to analyze the impact of digital transformation on corporate innovation, control for industry and year fixed effects, run parallel trend and placebo tests, output three-line tables"

## 12. FAQ

**Q: When should I use Focus Mode?**
A: Focus Mode uses a "plan first, execute later" strategy. Use it for complex multi-step tasks like full paper writing, project proposals, or competition reports. Simple Q&A doesn't need it.

**Q: Can Focus Mode, Deep Thinking, and Web Search be enabled simultaneously?**
A: Yes. They work independently. Combining them increases response time but maximizes capability.

**Q: I can't code at all. Can I really use this?**
A: Absolutely. DeepResValue's design philosophy is "zero code." Just describe your analysis needs in Chinese — AI handles everything from method selection to code writing to result output.

**Q: Are the AI results reliable and academically compliant?**
A: Yes. DeepResValue uses frontier LLMs, validated through thousands of real research projects. Every step preserves complete code and execution logs for full traceability.

**Q: What if I don't have data?**
A: The platform has built-in city/provincial/county and listed company panel data. Data collection skills access financial, health, medical, biological, and literature external sources.

**Q: What's the file size limit?**
A: Max 100MB per file, max 10 files per conversation. All formats except video are supported.

**Q: The AI expression is too obvious — what do I do?**
A: Use the built-in AIGC detection reduction engine. Say "help me reduce AIGC detection rate" in the chat.

**Q: The AI response was cut off.**
A: Send "please continue" to resume from the breakpoint. Refresh the page if needed — history is preserved.

**Q: How many sessions can run simultaneously?**
A: Maximum **2 concurrent sessions** per user.

**Q: What are MCP External Connectors?**
A: They let you call third-party data sources (PKULaw, Wind, etc.) directly in conversation. Platform doesn't charge extra service fees — you only pay for the third-party's own API costs (if any).

**Q: Can I use my own model (API Key)?**
A: Yes. BYOK (Bring Your Own Key) is supported. Go to Settings → Model Settings → Add Model Config. Supports any OpenAI-compatible HTTPS endpoint (DeepSeek, OpenAI, Moonshot, GLM, Qwen, etc.).

## 14. Platform Extensions

### 14.1 MCP External Connectors

External connectors (MCP, Model Context Protocol) let you call third-party professional data sources directly in conversation — without leaving the platform. After enabling, AI automatically determines when to call connectors.

**Available Connectors:**

| Connector | Type | Description |
|-----------|------|-------------|
| 🔍 PKULaw | Legal Search | Chinese laws, regulations, judicial cases, academic journals |
| 📊 Wind | Financial Data | Listed company financials, macroeconomic data, industry data |

**How to Enable:**

1. Click "External Connectors" in the sidebar
2. Select a connector
3. Enter your own API Token (BYOK)
4. Click "Save & Enable" — system verifies connectivity automatically

**Security:** Tokens encrypted with Fernet encryption; only last 4 characters shown. You can revoke access anytime.

### 14.2 BYOK — Bring Your Own Key

Use your own LLM API Key. After connecting, conversations use your model and quota — **the platform only charges base sandbox execution credits**.

**Supported Protocols:** OpenAI compatible (HTTPS) — covers DeepSeek, OpenAI, Moonshot, GLM, Qwen, and more.

**How to Add:**

1. Open **Settings** → **Model Settings**
2. Click **"Add Model Config"**
3. Fill in: API Base URL, API Key, Model Name
4. Optional: enable "Supports Deep Thinking" and "Supports Reasoning Levels"
5. Click "Test Connection" → save after success

**Security:** API keys are not displayed after saving (leave blank when editing to keep unchanged), stored encrypted on server. You can delete configs anytime.
