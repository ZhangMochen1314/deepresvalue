# 常见问题

以下是深度研值用户最常遇到的问题，分类整理供你快速查阅。

## 注册与登录

### 如何注册账号？

访问平台官网 [deepresvalue.top](https://deepresvalue.top)，点击右上角「获取内测资格」或「登录」，支持手机号注册——填写手机号和短信验证码即可快速登录。首次注册后系统将自动赠送初始积分。

### 对话记录会永久保存吗？

是的，所有对话记录保存在云端，与账号绑定，换设备登录后仍可访问。如需删除，右键侧边栏对话选择「删除」（删除后不可恢复）。

## 功能使用

### 我不会编程，真的能用吗？

完全可以。深度研值的设计理念就是「零代码」。你只需要用中文说出分析需求，AI 自动完成选方法、写代码、跑分析、出图表的全过程。平台的核心用户就是不懂编程的本科生。

### AI 生成的结果可靠吗？答辩时能用吗？

可靠。深度研值搭载顶尖推理引擎，经数千个真实科研场景项目验证。最关键的是，每一步分析都保留完整代码和执行日志——答辩时评委质疑，直接展示证据链，100% 可复现。

### 没有数据怎么办？

平台预置城市/省份/县域宏观面板与上市公司面板数据，数据搜集技能还可接入金融行情、健康、医学、生物、文献等外部数据源。用中文一句话描述需求，AI 精准返回结构化数据，不用中介代查，不花一分钱。

### 支持哪些文件格式？

支持 30+ 种文件格式，包括：

| 类型 | 格式 |
|------|------|
| 数据文件 | .csv .xlsx .xls .dta .sav .zsav .tsv .json |
| 文档文件 | .pdf .doc .docx .txt .md |
| 图片文件 | .png .jpg .jpeg .gif .svg .webp |
| 压缩包 | .zip .rar .7z .tar.gz |
| 脚本/代码 | .py .R .do .Rmd .sql .sas .ipynb |
| 空间数据 | .shp .shx .dbf .prj .geojson .kml .gpx |
| CAD/工程 | .dxf .stl .obj .ply .glb .gltf .3mf .off .idf .epw .tcl |

单个文件最大支持 **100MB**，单次对话最多上传 **10 个文件**。

### 上传的文件有大小限制吗？

单个文件最大支持 100MB，单次对话最多上传 10 个文件。如需处理超大文件，建议先分割或压缩后再上传。

### 同时能运行几个会话？

每个用户最多支持 **2 个会话同时进行**。当已有 2 个任务正在运行时，提交新任务会提示已达上限。您需要等待任意一个任务完成，或在侧边栏右键对话选择停止后释放配额。

## AIGC 相关

### AI 的学术痕迹太重，会被查出 AIGC 怎么办？

深度研值内置降 AIGC 引擎：21 组 AI 热词自动替换 + Best-of-N 改写策略 + 场景感知优化。实测可将 AIGC 检测率从 85% 降至安全线以下。

## 使用问题

### AI 回复中断了怎么办？

可尝试以下步骤：

1. 刷新页面后重新打开该对话，大部分情况下历史结果已保存
2. 若内容确实截断，在输入框中发送「请继续」，AI 会从断点继续生成
3. 如反复出现问题，请通过侧边栏底部的「帮助」入口联系技术支持

### 平台支持团队协作吗？

当前版本暂不支持多人实时协作。如需共享分析结果，可将 AI 生成的内容导出为 PDF 或 Markdown 后分享给队友。

## 积分相关

### 新用户有免费额度吗？

有。新用户注册即享免费使用额度，可立即体验完整功能。额度用尽后可按需充值积分继续使用。

### 积分不够用怎么办？

> 您可以通过以下方式获取更多积分：
> - **按需充值**：额度用尽后可随时充值积分继续使用
> - **邀请好友**：每成功邀请一人获得 +200 积分，**邀请奖励不设上限**
> - 使用他人邀请码注册可获得 +100 新人积分
> - 关注后续官方活动，可能有额外积分赠送

### 如何节省积分？

- 上传前精简文件——去掉无关列、只保留分析需要的观测值
- 一次把需求说清楚，避免反复追问导致重复消耗
- 合理控制数据范围和文件数量

## MCP 外部连接器

### 外部连接器（MCP）是什么？使用要额外收费吗？

外部连接器（MCP）让你在对话中直接调用第三方专业数据源（如智慧芽 PatSnap、北大法宝、万得 Wind、同花顺 iFinD、企查查等），无需离开平台。平台已集成**数十个 MCP 连接器**，覆盖专利/IP/法律/金融/企业/学术文献/地理/调研/会议/行情等，且**持续扩张中**。**平台不额外收取 MCP 连接器的服务费**，你只需承担第三方数据源本身的调用费用（如有）。你的 Token 采用加密存储，可随时停用或解绑吊销。
