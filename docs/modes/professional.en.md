# Professional Mode

Professional Mode lets you achieve Stata-grade data analysis in Chinese — no programming skills needed whatsoever. Just describe your needs and the full analysis workflow executes automatically.

## Who It's For

- Researchers conducting quantitative empirical analysis
- Students who don't know Stata/R/Python but need to run regressions
- Paper authors who need three-line tables, regression tables, and other standard outputs
- Research personnel with specific data analysis needs

## Features

| Feature | Description |
|---------|-------------|
| Natural Language Driven | Describe analysis needs in Chinese; AI auto-writes and executes code |
| 100+ Analysis Methods | Covers DID, IV, RDD, DML, Causal Forest, and other mainstream methods |
| Standardized Output | Journal-standard three-line tables, regression tables, visualizations |
| Full Code Preservation | Complete Python/R code and execution logs at every step |
| 100% Reproducible | Full analysis path displayable during defense |

## Supported Analysis Methods

| Category | Example Methods |
|----------|----------------|
| Traditional Econometrics | DID, IV, RDD, Synthetic Control, Panel Fixed Effects |

| Statistical Tests | Descriptive stats, correlation, t-test, ANOVA, chi-square |

## Example Prompts

> "Use DID to analyze this panel data, run parallel trend and placebo tests, output three-line tables."

> "Run descriptive statistics and correlation analysis on this data."

> "Use instrumental variables to address endogeneity — report the first-stage F-statistic."

## Analysis Workflow

1. **Upload data** — Supports Excel, CSV, Stata (.dta), SAS, SPSS, and 80+ formats. Max single file: 100MB.
2. **Describe needs** — State your analysis requirements in Chinese. The more specific, the better.
3. **AI auto-executes** — The AI automatically understands intent, selects methods, writes code, and performs analysis.
4. **Obtain results** — Outputs three-line tables, regression tables, and visualizations, ready for direct use in papers.

> Average turnaround: from data upload to complete results, approximately 2 minutes.

## How to Switch

1. **Enter the conversation interface** — Find the mode selection entry in the input box area.
2. **Select Professional Mode** — Click the mode toggle button and choose "Professional Mode."
3. **Start the conversation** — Takes effect immediately. Upload data files and enter analysis needs.

> Before uploading, streamline your data — remove irrelevant columns and keep only the observations needed for analysis. This effectively improves analysis speed and saves credits.
