# 专业模式

专业模式让你用中文实现 Stata 级别的数据分析——不会编程完全没关系，说出需求即可自动完成全流程分析。

## 适用人群

- 需要进行量化实证分析的研究者
- 不会 Stata/R/Python 但需要跑回归的同学
- 需要生成三线表、回归表等标准输出的论文作者
- 有明确数据分析需求的科研人员

## 功能特点

| 特点 | 说明 |
|------|------|
| 自然语言驱动 | 用中文说出分析需求，AI 自动写代码执行 |
| 50+ 分析方法 | 覆盖 DID、IV、RDD、DML、因果森林等主流方法 |
| 标准化输出 | 生成期刊标准的三线表、回归表、可视化图表 |
| 完整代码保留 | 每一步分析保留完整 Python 代码与执行日志 |
| 100% 可复现 | 答辩时可直接展示完整分析路径 |

## 支持的分析方法

| 类别 | 方法示例 |
|------|----------|
| 传统计量 | DID（双重差分）、IV（工具变量）、RDD（断点回归）、合成控制法、面板固定效应 |
| 因果机器学习 | DML（Double Machine Learning）、因果森林、Meta-learner |
| 统计检验 | 描述统计、相关性分析、t 检验、方差分析、卡方检验 |
| 机器学习 | 随机森林、XGBoost、神经网络、聚类分析、主成分分析 |
| 生存分析 | Kaplan-Meier 曲线、Cox 比例风险、竞争风险模型 |
| 空间计量 | 空间权重矩阵、莫兰指数、地理加权回归 (GWR) |
| 文本分析 | BERT/LLM 文本分类、情感分析、主题建模 |

> 试试这样问专业模式：
> - 「用 DID 分析这个面板数据，做平行趋势检验和安慰剂检验，输出三线表」
> - 「对这份数据做描述统计和相关性分析」
> - 「用工具变量法解决内生性问题，第一阶段 F 统计量要报告」

## 分析流程

1. **上传数据**
2. **描述需求**
3. **AI 自动执行**
4. **获取结果**

> 平均耗时：从上传数据到出完整分析结果，约 2 分钟。

## 如何切换

1. **进入对话界面**
2. **选择专业模式**
3. **开始对话**

> 建议上传前精简数据——去掉无关列、只保留分析需要的观测值，可有效提高分析速度并节省积分。
