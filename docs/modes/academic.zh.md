# 学术模式

学术模式提供从开题报告到毕业论文的一站式论文写作服务，覆盖科研写作全周期。

## 适用人群

- 正在撰写毕业论文的本硕博学生
- 需要发表期刊论文的研究者
- 准备开题报告或答辩材料的同学
- 需要文献综述和学术写作辅助的研究人员

## 功能特点

| 特点 | 说明 |
|------|------|
| 文献综述生成 | AI 自动检索中英文文献，提炼核心观点，生成结构化综述 |
| 开题报告 | 一键生成开题报告框架并填充文献综述 |
| 格式检查 | 自动检查参考文献格式、排版规范 |
| 答辩 PPT | 3 分钟生成答辩 PPT 大纲，梳理答辩逻辑 |
| 降 AIGC 引擎 | 内置 21 组 AI 热词替换 + Best-of-N 改写，论文安心提交 |

## 核心能力

### 论文写作全周期

| 阶段 | AI 能帮你做什么 |
|------|----------------|
| 选题阶段 | 评估选题可行性，推荐前沿方向 |
| 开题阶段 | 自动生成开题报告框架，填充文献综述 |
| 正文写作 | 润色段落、优化表达、自动检查学术规范 |
| 数据分析 | 50+ 方法自动匹配，出三线表 + 图表 |
| 格式检查 | 自动检查参考文献格式、排版规范 |
| 答辩准备 | 生成答辩 PPT 大纲，梳理答辩逻辑 |

### 降 AIGC 安心提交

- **21 组 AI 热词自动替换**：自动识别并替换「在当今时代」「值得注意的是」等 AI 高频用词
- **Best-of-N 改写策略**：为每段内容生成多个改写版本，自动选最优
- **场景感知 humanize**：根据上下文调整改写风格

> 试试这样问学术模式：
> - 「帮我写关于数字经济与碳排放的文献综述，引用近 3 年核心期刊」
> - 「帮我生成开题报告框架」
> - 「这段内容降 AIGC 处理一下」

## 如何切换

1. **进入对话界面**
2. **选择学术模式**
3. **开始对话**

> 降 AIGC 功能实测可将检测率从 85% 降至安全线以下，但建议结合人工润色以达到最佳效果。
