# Academic Mode

Academic Mode provides one-stop paper writing services from proposal to graduation thesis, covering the full research writing cycle.

## Who It's For

- Undergraduate, master's, and doctoral students writing graduation theses
- Researchers preparing journal paper submissions
- Students preparing proposals or defense materials
- Researchers needing literature review and academic writing assistance

## Features

| Feature | Description |
|---------|-------------|
| Literature Review Generation | AI auto-searches Chinese/English literature, extracts key findings, generates structured reviews |
| Proposal Writing | One-click proposal framework generation with populated literature review |
| Format Checking | Automatic verification of reference formatting and layout standards |
| Defense Slides | Generate defense PPT outline in 3 minutes, organize defense logic |
| AIGC Reduction Engine | Built-in 21 AI hot-word replacement + Best-of-N rewriting for confident submission |

## Core Capabilities

### Full-Cycle Paper Writing

| Stage | What AI Helps With |
|-------|-------------------|
| Topic Selection | Evaluate feasibility, recommend frontier directions |
| Proposal | Auto-generate proposal framework, populate literature review |
| Body Writing | Polish paragraphs, optimize expression, check academic standards |
| Data Analysis | 100+ methods auto-matched, three-line tables + charts |
| Format Check | Auto-check reference formatting and layout standards |
| Defense Prep | Generate defense PPT outline, organize defense logic |

### AIGC Reduction for Confident Submission

- **21 AI hot-word auto-replacement**: Identifies and replaces phrases like "in today's era," "notably," etc.
- **Best-of-N rewriting**: Multiple rewritten versions per paragraph, auto-selects optimal
- **Scene-aware humanization**: Adjusts rewriting style based on context

## Example Prompts

> "Write a literature review on digital economy and carbon emissions, citing recent 3-year core journals."

> "Generate a proposal framework for my research."

> "Reduce AIGC detection on this content."

## How to Switch

1. **Enter the conversation interface** — Find the mode selection entry in the input box area.
2. **Select Academic Mode** — Click the mode toggle button and choose "Academic Mode."
3. **Start the conversation** — Takes effect immediately. Enter your paper writing or literature needs.

> AIGC reduction testing shows detection rates reduced from 85% to below the safe threshold. Combining with manual polishing is recommended for optimal results.
