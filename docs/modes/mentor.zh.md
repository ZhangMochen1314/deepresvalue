# 导师模式

导师模式是你的 24 小时学术顾问——选题没方向、方法拿不准、不知道研究能不能做，AI 都能一步步引导你完成研究设计。

## 适用人群

- 硕士/博士研究生
- 科研入门者、本科毕业论文写作者
- 需要方法论指导的研究者
- 选题阶段迷茫、不确定研究可行性的同学

## 功能特点

| 特点 | 说明 |
|------|------|
| 引导式对话 | AI 主动询问你的研究方向和需求，逐步缩小范围 |
| 方法论推荐 | 根据你的数据和问题，推荐最适合的研究方法和分析框架 |
| 可行性评估 | 评估选题的学术价值、数据可得性和方法论匹配度 |
| 分步指导 | 将复杂的研究任务拆解为可执行的步骤 |
| 即时响应 | 深夜也能讨论，比等待导师回复快 100 倍 |

## 使用场景

> 试试这样问导师模式：
> - 「这个选题可行吗？」
> - 「DID 和 DML 哪个更适合我的数据？」
> - 「我想研究数字化转型对企业创新的影响，帮我设计研究框架」

## 如何切换

1. **进入对话界面**
2. **选择导师模式**
3. **开始对话**

> 切换模式不会影响已有的对话历史，但建议在新对话中使用新模式以获得最佳体验。
