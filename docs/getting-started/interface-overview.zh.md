# 界面概览

登录后进入主界面，了解各区域的功能可以帮助你更高效地使用平台。
## 主要区域

| 区域 | 位置 | 主要功能 |
|------|------|----------|
| **左侧侧边栏** | 屏幕左侧 | 对话列表、全局搜索、文件夹管理 |
| **主对话区** | 屏幕中央 | 消息输入、AI 回复展示、文件面板 |
| **顶栏** | 屏幕顶部 | 当前对话标题、积分余额显示、账户设置 |

## 左侧侧边栏

侧边栏是你管理所有对话的中心：

- **新建对话**：点击顶部「+ 新对话」按钮创建新的对话
- **对话列表**：显示所有历史对话，点击即可切换
- **搜索功能**：顶部搜索框支持关键词实时过滤
- **文件夹管理**：将相关对话分组归类整理
- **主题切换**：左侧主题按钮可切换界面风格
## 主对话区

主对话区是核心工作区域：

- **消息流**：AI 回复以流式方式逐步展示
- **输入框**：底部输入框用于发送消息和上传文件
- **文件面板**：右侧面板展示 AI 生成的文件（报告、图表、代码）
- **工具调用可视化**：实时显示 AI 调用的搜索、代码执行等工具
## 界面主题

提供 **四种界面主题**，点击侧边栏左侧的主题按钮即可切换：

| 主题 | 风格 | 适用场景 |
|------|------|----------|
| 暖色 | 米色暖调，柔和对比 | 长时间阅读，护眼 |
| 深蓝暗调 | 经典暗色配色 | 低光环境 |
| 浅色 | 中性蓝白，清晰明亮 | 通用日常 |
| 暗色 | 冷灰蓝深色背景 | 夜间使用 |
## 对话管理

### 文件夹管理

1. 点击侧边栏顶部的 **「+」** → **「新建文件夹」**
2. 输入文件夹名称（如「2026 毕业论文」「碳排放研究项目」）
3. 将对话拖拽到对应文件夹进行归类

### 对话操作

右键点击侧边栏中的任意对话：

| 操作 | 说明 |
|------|------|
| **置顶** | 将对话固定在列表最顶部 |
| **重命名** | 修改对话标题 |
| **删除** | 永久删除该对话（不可恢复） |

> 删除对话后不可恢复，请谨慎操作。所有对话记录保存在云端，与账号绑定，换设备登录后仍可访问。

### 并发会话限制

- 最多 **2 个会话同时进行**，互不干扰
- 超出限制时需等待任意一个任务完成，或停止正在运行的对话释放配额

> 如需开启新任务，可在侧边栏右键正在运行中的对话发送停止指令，即可释放一个配额。
