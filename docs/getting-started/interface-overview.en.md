# Interface Overview

After logging in, the main interface is divided into three areas. Understanding each area helps you use the platform more efficiently.

## Main Areas

| Area | Location | Primary Functions |
|------|----------|-------------------|
| **Left Sidebar** | Left side of screen | Conversation list, global search, folder management |
| **Main Chat Area** | Center of screen | Message input, AI response display, file panel |
| **Top Bar** | Top of screen | Current conversation title, credit balance, account settings |

## Left Sidebar

The sidebar is your central hub for managing all conversations:

- **New Conversation**: Click the "+ New Conversation" button at the top to start a fresh dialog
- **Conversation List**: Displays all past conversations; click any to switch
- **Search**: The search box at the top filters conversations by keyword in real time
- **Folder Management**: Group related conversations into folders for organization
- **Theme Switching**: The theme button on the left edge toggles between interface styles

## Main Chat Area

The main chat area is your core workspace:

- **Message Stream**: AI responses display incrementally via streaming
- **Input Box**: Located at the bottom, used for sending messages and uploading files
- **File Panel**: The right-side panel displays AI-generated files (reports, charts, code)
- **Tool Call Visualization**: Real-time display of AI-invoked tools — search, code execution, file reads

## Interface Themes

Five themes are available. Click the theme button on the left edge of the sidebar to switch:

| Theme | Style | Best For |
|-------|-------|----------|
| Follow System | Auto-matches OS theme | General use, automatic adaptation |
| Light | Neutral blue-white, clear and bright | Everyday use |
| Dark | Cool gray-blue dark background | Nighttime use |
| Solarized | Classic muted color scheme | Extended coding/reading |
| Warm | Beige warm tone, soft contrast | Extended reading, eye comfort |

## Conversation Management

### Folder Management

1. Click **"+"** at the top of the sidebar → **"New Folder"**
2. Name the folder (e.g., "2026 Thesis", "Carbon Emission Research")
3. Drag conversations into the corresponding folder

### Conversation Actions

Right-click any conversation in the sidebar:

| Action | Description |
|--------|-------------|
| **Pin** | Fix the conversation at the top of the list |
| **Rename** | Change the conversation title |
| **Delete** | Permanently delete the conversation (irreversible) |
| **Export** | Export conversation as Markdown or JSON |

> Up to **5 conversations** can be pinned simultaneously.

### Concurrent Session Limit

- Maximum **2 sessions** running at the same time, operating independently
- Exceeding the limit requires waiting for one task to finish, or stopping a running conversation to free a slot

> To free a slot, right-click a running conversation in the sidebar and send a stop command.

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|
| **Cmd/Ctrl + K** | Open command palette (globally available) |
| **Cmd/Ctrl + Shift + N** | New conversation |
| **Cmd/Ctrl + B** | Toggle left sidebar |
| **Cmd/Ctrl + ,** | Open settings |
| **Cmd/Ctrl + /** | View keyboard shortcuts |
| **Enter** | Send message from input box |
