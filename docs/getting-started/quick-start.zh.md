# 快速开始

**零安装零配置**——四大计算内核 + Word/LaTeX 排版引擎全部云端预配置，打开网页即得满配科研环境。手机、平板、电脑三端互通，随时随地开展科研。只需几分钟，即可开始使用深度研值进行专业科研分析。

> 首次注册后系统将自动赠送初始积分，可立即体验完整功能。

## 创建第一个对话

1. **新建对话**
2. **输入问题**
3. **查看结果**

## 如何写好 Prompt

任务描述越具体，AI 输出越精准。

| 质量 | 示例 |
|------|------|
| ❌ 不够好 | 「帮我做个分析」 |
| ✅ 更精准 | 「用 DID 方法分析数字化转型对企业创新的影响，控制行业和年份固定效应，做平行趋势检验和安慰剂检验，输出三线表」 |

> 一次把需求说清楚可以节省积分消耗，避免反复追问导致重复扣费。

## 三种使用模式

深度研值提供三种模式，按需切换：

### 🎓 导师模式

你的 24 小时学术顾问。选题没方向？方法拿不准？AI 一步步引导你完成研究设计、推荐最优方法、评估可行性。

```text
试试这样问：「这个选题可行吗？」「DID 和 DML 哪个更适合我的数据？」
```

### 📝 学术模式

论文一条龙服务——从开题报告到毕业论文，从文献综述到答辩 PPT，一站式搞定。内置降 AIGC 引擎，论文安心提交。

```text
试试这样问：「帮我写关于数字经济与碳排放的文献综述，引用近 3 年核心期刊」
```

### ⚡ 专业模式

Stata 级分析，说中文就行。用中文说出分析需求，AI 自动写 Python 代码、执行回归、生成表格和图表。

```text
试试这样问：「用 DID 分析这个面板数据，做平行趋势检验，输出三线表」
```
